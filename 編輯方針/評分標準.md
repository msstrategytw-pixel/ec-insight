# 評分標準（v0.1 草稿）

每篇候選文章依三個維度評分（各 1–5 分），**總分 ≥ 9 才刊登**。門檻跑一週後檢討：簡報太長就調高、太空就調低。

## 三個維度

### 影響廣度（1–5）：多少商家受影響？

- 5：幾乎所有商家（如 Meta 廣告政策、金流費率調整）  
- 3：一到兩個產業的多數商家（如食品標示新法規）  
- 1：單一品牌或極小眾（如某小眾品牌的公關稿）

### 行動性（1–5）：讀完能做什麼？

- 5：有明確可執行動作與時限（「9/1 前需完成 XX 設定」）  
- 3：能納入決策參考（備貨、定價、檔期規劃）  
- 1：只能「知道一下」，無法據此做任何事

### 時效性（1–5）：現在不知道會怎樣？

- 5：有截止日或正在發生的事件  
- 3：近期趨勢，一個月內談都有意義  
- 1：舊聞或常識

## 範例庫（優化 agent 選材的主要工具）

> 覺得選材不準時，優先在這裡加範例，比改上面的定義有效。格式：文章標題／連結、當時的處理、應該的處理、原因。

### ✅ 應該選的範例

| 文章 | 原因 |
| :---- | :---- |
| （待累積）例：「Google 宣布 2026 年 Q4 起調整購物廣告費率」 | 影響廣 5＋行動 4＋時效 5＝14。所有投廣告的商家都要重算成本 |
| （待累積）例：「經濟部統計：6 月零售業網路銷售額年增 X%」 | 官方數據、顧問跟商家對話的共同基準 |

### ❌ 不該選的範例

| 文章 | 原因 |
| :---- | :---- |
| （待累積）例：「某新創完成 A 輪募資，要用 AI 顛覆電商」 | 影響廣 1＋行動 1。沒有商家能據此做任何事 |
| （待累積）例：「2026 電商十大趨勢預測」年初盤點文 | 空泛、無操作含量、時效低 |

## 其他規則

- 同一事件多來源報導 → 合併為一則，取最完整的來源為主連結  
- 摘要只根據抓到的原文撰寫，禁止補充外部知識或推估數字；原文沒寫的就寫「原文未提及」  
- 每則必附原文連結；廠商自家內容標註「廠商內容」；社群討論標註「社群觀點」
