# 外站趨勢 tab — 蒐集方針（v0.1 草稿）

## 這個 tab 要回答的問題

**「其他平台上什麼在熱賣？有什麼選品與定價的訊號？」**

核心原則：**榜單的「變化」才有價值，單日快照沒有。** 所以這個 tab 的資料必須留存歷史，每次產出都與上期比較：新進榜、排名飆升、跌出榜的品項。

## 資料目標（依實現難度排序）

### 第一優先：酷澎（Coupang 台灣）
- 目標：分類熱銷排行頁（公開網頁）
- 頻率：每日一次，低頻抓取
- 記錄欄位：日期、分類、名次、品名、價格、（若有）折扣與評價數
- 產出：與前一日／前一週比較的變化清單

### 第二優先：海外公開榜單（好抓、看趨勢先行指標）
- Amazon Best Sellers（美、日站）：關注美妝、居家、3C 等與台灣重疊品類
- 日本樂天排行：日系商品趨勢常領先台灣 3–6 個月
- 頻率：每週一次即可

### 蝦皮（實驗中，暫用降級方案）
- 反爬蟲強度高，直接抓榜單成功率低、易失敗
- **暫行方案**：蒐集蝦皮官方發布的趨勢報告、購物節戰報、新聞稿
- **實驗方案**：低頻 headless browser 抓公開熱銷排行頁，穩定後再納入正式 pipeline
- 注意：抓取行為需留意平台服務條款，僅供內部參考使用

## 分析與撰寫要求

- 不逐項羅列榜單（那是資料，不是資訊）。每期挑 3–5 個**有意義的變化**寫成條目：某品類集體上榜、某類商品價格帶下移、某海外爆品可能登台
- 每個條目要回答：**這對我們商家的選品／定價是什麼訊號？**
- 誠實標註資料侷限：榜單反映的是該平台客群，不等於全市場
