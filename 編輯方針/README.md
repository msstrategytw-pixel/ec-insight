# 編輯方針（Editorial Config）

這個資料夾是整個資訊蒐集 agent 的「大腦設定」。Agent 每次執行時會先讀取這裡的所有文件，再據此決定：去哪裡找資料、什麼算重要、怎麼寫摘要。

**改這裡的文件 = 調整 agent 的行為，不需要動任何程式碼。**

## 修改守則

1. **用自然語言寫就好**。這些文件是給 AI 讀的，寫得像在跟一個新進同事交接即可，不需要任何特殊格式。
2. **改範例比改定義有效**。覺得 agent 選材不準時，優先去[評分標準.md](評分標準.md)的範例庫加一筆「這篇不該選（原因）」或「這種要多選（原因）」，比修改抽象定義見效快。
3. **大改先試跑**。大幅修改方針後，可以要求 agent 用新方針重跑前一天的文章做對照（哪些會被刷掉、哪些會新增），確認方向再生效。
4. 每次修改請在文件最下方的「修改紀錄」加一行：日期、誰、改了什麼、為什麼。這讓之後對照「有用率」變化時知道是哪次修改造成的。
