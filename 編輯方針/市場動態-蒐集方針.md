# 市場動態 tab — 蒐集方針（v0.1 草稿）

## 這個 tab 要回答的問題

**「八大產業這週發生了什麼，會改變商家的進貨、定價、行銷檔期決策？」**

產業定義與各產業特別關注面向，見[產業清單.md](產業清單.md)。本文件寫共通規則。

## 蒐集面向（依優先序）

1. **重大事件**：影響某產業的法規變動、食安／安全事件、關稅與進出口政策、原物料價格劇烈變動
2. **通路與競局動態**：momo、PChome、蝦皮、酷澎、統一超、全聯、寶雅等大型通路的策略動作（這些是產業風向球）；重要品牌的進出場、併購
3. **數據與報告**：經濟部統計處零售業營業額、各產業公協會報告、市調機構（Kantar、NIQ、未來流通研究所）發布的數字
4. **消費趨勢**：有數據支撐的消費行為變化（不是單一 KOL 的觀察）

## 來源清單

**財經媒體**：經濟日報、工商時報、中央社商情
**產業媒體**：食力（食品）、美業誌類（美妝）、動誌類（運動）——各產業媒體由該產業顧問持續補充
**官方數據**：經濟部統計處（每月 23 日左右發布零售業營業額）、財政部進出口統計
**公司資訊**：富邦媒（momo）、網家（PChome）、統一超等的月營收公告與法說會

## 選材標準

**要選**：
- 會改變商家「決策」的消息：要不要提前備貨、要不要調價、檔期要不要提前
- 有數字的：營收年增率、市占變化、價格漲幅
- 大通路的策略轉向（例如某通路大力補貼某品類 → 該品類商家的機會或威脅）

**不選**：
- 單一品牌的例行公關稿（新品上市、週年慶）——除非規模大到牽動整個品類
- 與台灣市場無關的海外產業新聞（除非有明確的傳導路徑，如國際原物料價格）

## 摘要撰寫要求

每則條目標註所屬產業（可多個）。格式同電商經營 tab：一句話重點 → 摘要（含數字）→ **對該產業商家的意義** → 原文連結。同一事件多家媒體報導時合併為一則、附多個來源。持續發展中的事件（如某法規進入不同階段）標註「後續追蹤」，更新既有條目而非重發。
